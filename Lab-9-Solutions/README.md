# Lab 9 — Exploratory Testing with an AI Co-Pilot

Includes a 45-minute test charter, five AI-suggested avenues, timestamped note sheet, and session report template aligned to the lab manual. The notes are intentionally marked as planned rather than fabricated observations.

## Complete the session
1. Open `test_charter.md`; start a 45-minute timer only when ready.
2. Explore the task manager and enter each observation immediately in `session_notes.csv` with a real timestamp and evidence.
3. Stop at 45 minutes. Reproduce each suspected bug and tag severity/source.
4. Fill `reports/session_report_template.md` using confirmed evidence only.
